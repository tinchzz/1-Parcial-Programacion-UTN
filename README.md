Explicación Programa "NOTA FACIL" desde la vista de un usuario:
El usuario ve por pantalla el siguiente menú: 
1. Cargar alumnos
2. Mostrar listado
3. Mostrar estadísticas
4. Ver ranking (ordenado)
5. Buscar alumno
6. Juegos con un nombre
0. Salir
Ingresa por pantalla la opción que desea.

Modulo 1. Carga de alumnos
Solicita ingresar la cantidad de alumnos que necesite.
Se ingresa nombre, nota del primer y del segundo parcial.
Internamente se hace un promedio de ambas notas

Modulo 2. Mostrar listado
Consulta si ya existen alumnos ingresados.
Si existen, se muestran ID y Nombre de los alumnos ingresados

Modulo 3. Mostrar estadísticas
Consulta si ya existen alumnos ingresados.
Si existen, se muestra el Promedio General de los alumnos ingresados y el Mejor y el Peor promedio entre los alumnos ingresados

Modulo 4. Ver ranking ordenado
Consulta si ya existen alumnos ingresados.
Si existen, se utiliza el ordenamiento en burbuja para mostrar de mayor a menor los promedios entre los alumnos

Modulo 5. Buscar alumno
Consulta si ya existen alumnos ingresados.
Si existen, se puede buscar los alumnos por ID (Modulo 2. Mostrar listado) o por nombre del alumno. Muestra sus notas y el promedio.

Modulo 6. Juegos con un nombre
Solicita ingresar el nombre de un alumno.
El sistema muestra cuantas vocales tiene el nombre del alumno y su nombre escrito al reves.

Modulo 0. Salir
Termina el programa
